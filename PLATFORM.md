# Windows x64 edition

This branch packages Blender-Sith extension **1.0.4** for `windows-x64` in
distribution release **v1.0.4-coda.1**. It shares the common implementation,
including native radius and pivot repairs, with all platform branches.

See [installation and platform builds](docs/platform-builds.md), the
[exact release validation](docs/release-1.0.4-coda.1.md), and the
[fork attribution and limitations](FORK.md). Download the installable extension
ZIP from [GitHub](https://github.com/CodaLilitari/blender-sith/releases/tag/v1.0.4-coda.1)
or [GitLab](https://gitlab.com/codalilitari/blender-sith/-/releases/v1.0.4-coda.1).
These packages do not include Blender itself. Background validation is distinct
from interactive installation and game-runtime acceptance.
